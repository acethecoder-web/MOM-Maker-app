## ✨ Features

✅ Generate meeting minutes from pasted transcripts

✅ Upload and analyze `.docx` meeting documents

✅ AI-generated meeting summaries

✅ Extract key discussion points

✅ Capture decisions made during meetings

✅ Identify action items, owners, and due dates

✅ Simple and lightweight web interface

✅ REST API for integration with other applications
